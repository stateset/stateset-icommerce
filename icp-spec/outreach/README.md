# Outreach playbook

These are the actual messages to send. PROTOCOL-RFC.md is the artifact;
this directory is the *delivery vehicle*. No vague pings, no LinkedIn
spray — every message names the seam, makes one specific ask, and links
to one concrete artifact.

## Sequence

Send in this order over a 10-business-day window. Don't go broad until
you've heard back from at least one. The first reply shapes the framing
for the next.

**Circle is now the highest-priority outreach** alongside Coinbase: they
are the named operator for the first reference Settler. No real volume
moves through ICP until a regulated operator runs `settler:circle.usdc.base`.

## Tone rules

- Lead with the seam, not the codebase.
- Quote one number that proves seriousness (250k LOC, 15.8k tests, v1.0.4
  shipping). Don't list features.
- Make exactly one ask per message. Reading time goal: under 90 seconds.
- Offer to do the work. They have no spare bandwidth; you do.
- If they say no, ask "who at $COMPANY would say yes?" and act on it.
