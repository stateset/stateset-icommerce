# StateSet iCommerce

StateSet iCommerce is an embedded, AI-native commerce engine designed to run in-process with zero external dependencies. It provides a full commerce and ERP surface area with deterministic operations that AI agents can safely call.

## What you get

- Local-first execution with SQLite and an optional PostgreSQL backend.
- Consistent domain APIs across 11 language bindings.
- A CLI and MCP tools for agent-driven workflows.
- Deterministic operations designed for automation and auditability.

Current release: **0.7.27**. This book tracks the latest main branch. For release snapshots, see [Versioning](versioning.md).
