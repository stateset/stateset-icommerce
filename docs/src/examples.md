# Examples

Real-world scenarios live in `examples/` with runnable scripts across 9 languages.

## Scenarios

### 1) AI customer support agent

- Look up orders, update status, and issue refunds.
- Pair MCP tools with the CLI for safe, auditable actions.
- See: `examples/workflows.md` and `examples/cli-reference.md`.

### 2) Offline POS with sync

- Run locally on SQLite, reconcile via VES when online.
- See: `examples/getting-started-sync.md`, `examples/setup-sync.sh`.

### 3) Subscription billing and invoicing

- Create plans, subscriptions, and invoice flows.
- See: `examples/workflows.md` and `examples/basic_usage.rs`.

### 4) Manufacturing and procurement

- Build BOMs, create work orders, and generate POs.
- See: `examples/workflows.md`.

## Language examples
