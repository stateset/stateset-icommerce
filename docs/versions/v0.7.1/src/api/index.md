# API Reference

Each binding exposes the same core commerce surface. This section points to the authoritative API definitions in each binding and the primary entry points.

Generated API docs (when available) live under `docs/api/` and are refreshed during releases (see `RELEASING.md`).

## Common APIs

All bindings expose a consistent surface area:

- Customers
- Products and variants
- Orders and fulfillment
- Inventory and reservations
- Carts and checkout
- Payments and refunds
- Returns (RMA)
- Analytics and forecasting
- Tax and promotions
- Subscriptions and billing
