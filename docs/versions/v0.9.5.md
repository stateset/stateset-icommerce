# StateSet iCommerce v0.9.5 Release Notes

**Release Date:** 2026-04-03  
**Tag:** [`v0.9.5`](https://github.com/stateset/stateset-icommerce/releases/tag/v0.9.5)

## Overview

v0.9.5 is a runtime trust-hardening release. It focuses on fail-closed permissions, durable degraded-mode persistence, and clearer repo-native trust documentation rather than new product surface area.

**60 files changed** | **runtime trust fixes + release metadata sync**

---

## Highlights

### Fail-closed permissions

- MCP permission checks now fail closed for unknown tools.
- Tool permission metadata is aligned with the runtime permission map.
- Permission coverage was extended so exposed tools are checked against the runtime gate.

### Durable fallback persistence

- Audit logs, credentials, treasury records, channel identity/session state, agent sessions, conversation memory, and ERC-8004 identity storage now persist to durable JSON fallback stores when `better-sqlite3` is unavailable.
- Degraded fallback mode now emits explicit warnings instead of silently behaving like durable storage.

### Runtime hygiene

- Session cleanup now enforces configured retention caps correctly.
- Channel-session fallback upserts now preserve the correct field ordering.
- Trust posture and roadmap documents were added to make implemented vs planned guarantees clearer.

```bash

npm install
```
