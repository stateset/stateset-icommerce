# StateSet iCommerce v0.7.2 Release Notes

**Release Date:** 2026-02-20  
**Tag:** [`v0.7.2`](https://github.com/stateset/stateset-icommerce/releases/tag/v0.7.2)

---

## Overview

v0.7.2 focuses on operational workflows and observability: adding a structured data-import path for Shopify, expanding MCP/CLI tooling, and improving policy transparency for agent actions.

**35 files added** | **168 files modified** | **10760 insertions** | **313 deletions**

---

## Highlights

- Added a new `stateset-import` CLI command for import/export workflows.
- Introduced a reusable import framework:
  - Adapter interface (`BasePlatformAdapter`)
  - Shared importer (`DataImporter`)
  - ID mapping store (`IdMapStore`) for incremental imports and cross-reference lookups
- Added Shopify import support for API/CSV/JSON sources with CSV parsing and dependency-aware import ordering.
- Expanded MCP to include new import/export tools:
  - `import_shopify_data`
  - `import_status`
  - `list_id_mappings`
  - `import_csv`
  - `import_json`
  - `export_data`
- Improved policy engine output and explainability:
  - condition/action detail tracing
  - policy remediation fields
  - explanations attached to policy decisions
  - dry-run policy evaluation
- Added MCP response shaping for structured telemetry metadata via the `--structured-tool-results` flow.

---

## Added

### CLI & MCP

- New bin command `stateset-import` with:
  - preview mode (`--apply` gating for writes)
  - JSON/CSV/YAML output support
  - session resume support
  - optional streaming response mode
- New permission mappings for import tools in `cli/src/permissions.js`.
- New MCP event tooling support for machine-readable result metadata.

### Import Stack

- New adapter registry and tooling layer under `cli/src/adapters/*`:
  - platform adapter abstraction
  - import orchestrator
  - ID mapping persistence in SQLite
  - Shopify adapter + CSV parser + client + importer
- Import result reporting includes counts for created/skipped/failed records and per-entity progress.
- Export helper support to support parity and validation workflows.

### Policy & Observability

- Policy engine now returns structured explanations and remediation details for evaluation outcomes.
- Deny/allow precedence and dry-run policy evaluation were made explicit for safer policy simulation.
- MCP now includes structured metadata in tool responses (policy/permission/charge/timing) when structured output is enabled.

---

## Changed

- Workspace and binding version metadata synchronized to `0.7.2` across:
  - Rust crates
  - CLI package
  - language bindings and examples
  - documentation references
- MCP tooling behavior now returns richer structured error paths for policy/permission/treasury blocks in addition to normal success/error payloads.
- Shopify import path includes strict domain validation and basic request-rate limiting in the Shopify client.
- Webhook delivery validation in embedded eventing now applies stricter public-host safety checks.

## Tests

- Added/updated import and adapter test coverage around:
  - adapter base behavior
  - chains configuration/validation
  - import parity and import tools
  - Shopify mapping/parsing/webhook handling
  - policy explainability and security-path coverage
- These additions improve confidence around the new import workflow and policy decision tracing.
