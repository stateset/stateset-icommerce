# StateSet iCommerce v0.7.4 Release Notes

**Release Date:** 2026-02-23  
**Tag:** [`v0.7.4`](https://github.com/stateset/stateset-icommerce/releases/tag/v0.7.4)

---

## Overview

v0.7.4 aligns release metadata across the workspace, CLI runtime, and language bindings to `0.7.4`, with additional packaging and template updates needed for coherent releases.

**178 files changed** | **6,460 insertions** | **1,373 deletions**

---

## Added

- Added `stateset-setup` CLI binary entry in `package.json`.
- Added `@clack/prompts` dependency for interactive CLI UX flows.
- Added `stateset-crypto` to workspace and Node wrapper dependency graph.

## Changed

- Bumped workspace and cross-language metadata from `0.7.2` to `0.7.4` across Rust crates, CLI packages, language bindings, examples, and docs.
- Updated CLI/version runtime references (`CLI_VERSION`, health endpoint fallback, scaffold templates, WhatsApp user agent) to `0.7.4`.
- Updated npm lockfiles/package manifests to reference `0.7.4`.
- Adjusted selected CLI logs from `console.log` to `console.debug`/`console.info`.
- Updated lockfile dependency graph for crypto-related workspace crates.

## Fixed

- Aligned version checks and dependency specifiers in examples/bindings to `0.7.4`.

## Tests

- Updated version-aware test expectations to validate `0.7.4` in CLI test suites:
  - `cli/tests/v028-features.test.js`
  - `cli/tests/v030-integration.test.js`

## Upgrading

```bash
git fetch --tags
git checkout v0.7.4
```

For Rust:

```bash
cargo build --release
```

For CLI:

```bash
cd cli
npm install
```

No data migration steps are required for existing installations.
