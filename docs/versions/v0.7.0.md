# StateSet iCommerce v0.7.0 Release Notes

**Release Date:** 2026-02-07
**Tag:** [`v0.7.0`](https://github.com/stateset/stateset-icommerce/releases/tag/v0.7.0)

---

## Overview

v0.7.0 is a quality, security, and reliability release. It introduces **1,842 automated tests**, hardens the CLI and admin surfaces against common attack vectors, and establishes code-quality tooling that enforces standards on every commit.

**535 files changed** | **65,524 insertions** | **24,186 deletions**

---

## Highlights

### Testing: 0 → 1,842 automated tests

| Target | Tests | Runner |
|--------|-------|--------|
| CLI    | 1,581 | `node --test` |
| Admin  | 261   | Vitest + jsdom |
| **Total** | **1,842** | **0 failures** |

40+ new unit test files covering: permissions, telemetry, errors, HTTP gateway/auth, the full channels subsystem (middleware, rich-messages, templates, event-bridge, gateway-methods, notifier, handoff, metrics, adapter-types), context, credentials, session persistence, MCP schema validator, command queue, rate limiter, graceful shutdown, and more.

### Security Hardening

- **Command injection prevention** — `scaffold-server` uses an allowlist; `marketplace` and `gateway` switched to `execFileSync`.
- **SQL injection prevention** — `treasury/store.js` enforces a hardcoded column whitelist.
- **Path traversal prevention** — `safeIdSchema` validation on admin API routes.
- **Cryptographic randomness** — `Math.random()` replaced with `crypto.randomUUID()` across conversation context, tool composer, and error boundary.
- **MCP SDK upgrade** — `@modelcontextprotocol/sdk` ^1.25.4 → ^1.26.0 (fixes GHSA-345p-7cg4-v4c7).
- **Security headers** — CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy on the HTTP gateway.
- **Body size limits** — enforced on HTTP gateway and admin API routes.
- **Secrets management** — `secrets.yaml` → `secrets.yaml.template`; real secrets gitignored.
- **Silent catch cleanup** — ~15 empty `catch {}` blocks replaced with `console.warn()` for observability.

### Rate Limiting

In-memory sliding-window rate limiter on the HTTP gateway:
- **Per API key:** 60 requests/minute
- **Per IP address:** 30 requests/minute

### Graceful Shutdown

All 47 `bin/` entry points now handle `SIGINT`/`SIGTERM` with proper cleanup via `runMain()` or `installShutdownHandlers()`.

### Permission System Expansion

- **168+ MCP tools** mapped to permission gates (up from 64).
- Persistent SQLite audit log (`audit-store.js`) recording all gate decisions.

### Code Quality Tooling

| Tool | Purpose |
|------|---------|
| ESLint (flat config) | Linting for CLI JS files |
| eslint-config-prettier | Prevents ESLint/Prettier conflicts |
| Prettier | Consistent formatting across CLI + admin |
| commitlint | Conventional commit message enforcement |
| Husky | `pre-commit` (format check) + `commit-msg` (commitlint) hooks |
| jsconfig.json | Type checking via JSDoc + `checkJs` |

All checks run in CI.

## Bug Fixes

- **mcp-schema-validator.js** — `.optional().regex()` reordered to `.regex().optional()` (Zod API order matters).
- **x402/budget.js** — `DEFAULT_STATE` shared mutable references replaced with deep copy in `createBudgetState`.
- **credentials.js** — silent `.catch(() => {})` replaced with `console.warn`.
- **session-persistence** — TTL race condition in tests (1ms → 5000ms).
- **runMain()** — `Promise.resolve()` fix for sync main functions.
- **Streaming providers** — error handling added to catch blocks in `gemini.js`, `ollama.js`, `openai.js`.
- **Admin sessions route** — silent `.catch(() => ({}))` replaced with proper error handling.
