# StateSet iCommerce v0.9.4 Release Notes

**Release Date:** 2026-04-02

## Overview

v0.9.4 moves the x402 integration much closer to the x402 v2 exact-EVM model. It adds standards-shaped exact payment payloads, facilitator and resource-server helpers, exact-flow examples, Sepolia testnet coverage, and shared release-hygiene automation across CI and publishing workflows.

**75 files changed** | **2,667 insertions** | **220 deletions**

---

## Highlights

### x402 v2 exact-EVM flow

- Added exact-EVM `PAYMENT-SIGNATURE` retry support in the CLI x402 client flow.
- Added exported helpers for exact-EVM payment creation, verification, settlement, CAIP-2 network mapping, and supported-kind discovery.
- Added reusable x402 facilitator helpers and HTTP handlers for `/supported`, `/verify`, and `/settle`.
- Added reusable resource-server helpers that emit `payment-required`, validate incoming payments, settle accepted authorizations, and return `PAYMENT-RESPONSE`.

### Testnet coverage

- Added Base Sepolia support with testnet USDC metadata.
- Added Ethereum Sepolia support with testnet USDC metadata.
- Added runnable exact-flow examples for both facilitator and resource-server integration paths.

### Interop hardening

- Bound legacy JavaScript x402 signing hashes to `resourceUri` and `resourceMethod`, matching the Rust-side replay protections.
- Removed the legacy sequencer requirement from exact-x402 MCP calls while preserving explicit errors for legacy sequencer-backed flows.
- Tightened exact-EVM validation around authorization windows and requirement matching.

### Release hygiene

- Added `scripts/ci/check_release_hygiene.sh` for shared release preflight validation.
- Added regression coverage for the release helper in `scripts/ci/check_release_hygiene.test.sh`.
- Updated publish workflows to gate on release-hygiene checks.
- Added workflow lint coverage via `.github/scripts/actionlint.sh` and CI wiring.
