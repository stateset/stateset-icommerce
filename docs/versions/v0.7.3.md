# StateSet iCommerce v0.7.3 Release Notes

**Release Date:** 2026-02-22  
**Tag:** [`v0.7.3`](https://github.com/stateset/stateset-icommerce/releases/tag/v0.7.3)

---

## Overview

v0.7.3 aligns release metadata across the workspace and bindings to `0.7.3`, and includes a few CLI/runtime metadata updates introduced during this release cut.

**42 files changed** | **218 insertions** | **111 deletions**

---

## Added

- Added `stateset-setup` CLI binary entrypoint to `cli/package.json`:
  - `stateset-setup: bin/stateset-setup.js`
- Added `@clack/prompts` as an optional dependency in CLI to support interactive UI flows.

## Changed

- Bumped workspace/package versions and internal crate dependency metadata from `0.7.2` to `0.7.3` across:
  - Rust workspace package manifest (`Cargo.toml`)
  - `Cargo.lock`
  - `bindings/**` manifests and language binding metadata
  - CLI and example package manifests and generated templates
- Added `stateset-crypto` as a workspace member/dependency and wired it into Node wrapper dependencies.
- Updated npm lockfiles (`bindings/node`, `cli`) to `0.7.3`.
- Updated embedded CLI/runtime version constants and generated template defaults from `0.7.2` to `0.7.3`.
- Updated JS runtime logging style for selected paths from `console.log` to `console.info` / `console.debug` in:
  - `cli/src/channels/http-gateway.js`
  - `cli/src/whatsapp/session.js`

## Fixed

- Version checks and examples now consistently reference `0.7.3` in:
  - `examples/node/package.json`
  - `examples/python/requirements.txt`
  - `examples/ruby/Gemfile`
  - `cli/src/channels/http-gateway.js` health endpoint

## Tests

- Updated version-aware tests to validate `0.7.3` in CLI test suites:
  - `cli/tests/v028-features.test.js`
  - `cli/tests/v030-integration.test.js`

## Upgrading

```bash
git fetch --tags
git checkout v0.7.3
```

For Rust:

```bash
cargo build --release
```

For CLI:

```bash
cd cli
npm install
```

No data migration steps are required for existing installations.
